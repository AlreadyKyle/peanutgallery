# Paths no agent may change, in any lane (docs/specs/launch-hardening.md, docs/specs/launch-gate.md,
# docs/specs/board-site.md, PLAN.md §4 Kernel). In platform/site that is the build and its entry
# (index.html, main.tsx), the frame and routes of every page (App.tsx), the money (the Payment Link and
# what reads, formats, states or shows money, and the snapshot every figure comes through, with the
# Netlify Function that serves it, platform/site/netlify), the ledger and the legal pages, and the
# design checks a card could otherwise switch off (the end-to-end suite and its fixtures in
# platform/site/e2e, styles.test.ts with the colour and contrast maths it reads, copy.test.ts, and
# seed-1's frame spec and its Playwright config; docs/specs/design-review.md); the whole board site is
# kernel. The files that set the look are a separate, board-only list, design-paths.txt. A kernel file in platform/site/src imports only
# kernel files, packages, copy.ts, PageHeader.tsx, styles.css, freshness.ts and routes.tsx
# (platform/dispatcher/test/site-kernel.test.ts). One repository-relative path per line; a folder
# covers everything under it. The dispatcher refuses a card that changes one, the gate fails a card
# branch that does, and the gate's build job restores every one of them from the base commit before it
# installs or builds.
